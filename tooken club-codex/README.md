# Учёт расходов

Приложение работает на Python 3.12 и использует только стандартную библиотеку. Данные хранятся рядом с `main.py` в файле `expenses.json`; файл создаётся автоматически при первом запуске.

## Запуск

```text
python main.py add 1250.50 Продукты
python main.py add 300 Транспорт
python main.py list
python main.py summary
```

Команда `add` принимает положительную сумму и непустую категорию. Десятичную часть суммы можно указывать через точку или запятую.
