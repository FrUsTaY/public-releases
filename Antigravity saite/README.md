# PIXEL SERVICE — Сервисный центр цифровой техники

Современный, технологичный и интерактивный веб-сайт сервисного центра по ремонту цифровой электроники и компьютерной техники (ноутбуки, игровые ПК, смартфоны, планшеты, видеокарты, консоли, мониторы).

Сайт разработан в соответствии с техническим заданием (стиль Premium Tech / Minimalist Dark), включает **4 полнофункциональных интерактивных калькулятора**, полную валидацию форм, адаптивный мобильный интерфейс, проверку физической и электрической совместимости компонентов и централизованную конфигурацию данных.

---

## ⚡ Ключевые возможности проекта

### 1. 🧮 Четыре интерактивных калькулятора
1. **Калькулятор стоимости ремонта цифровой техники:**
   - Выбор устройства (Ноутбуки, ПК, Смартфоны, Планшеты, Видеокарты, Консоли).
   - Выбор марки / серии устройства.
   - Выбор неисправности (BGA, цепи питания, залитие, замена экрана, перегрев и т.д.).
   - Дополнительные услуги (срочность, резервное копирование данных, премиальный термоинтерфейс Honeywell PTM7950, курьер, расширенная гарантия).
   - Автоматический расчёт сметы и сроков с обязательным дисклеймером и возможностью переноса расчёта в форму заявки.
2. **Калькулятор обслуживания ПК:**
   - Интерактивный чек-лист регламентных работ (чистка, термопаста CPU, термопаста GPU, замена термопрокладок, СЖО, стресс-тесты, кабель-менеджмент).
   - Пакетное предложение «Полная профилактика» с выгодой 40%.
   - Автоматическая скидка 15% при выборе комбо из 3+ услуг.
3. **Конфигуратор сборки ПК с реальной проверкой совместимости:**
   - Полноценный каталог компонентов: CPU, материнские платы, GPU, RAM, SSD, БП, корпуса, системы охлаждения.
   - **Алгоритмическая проверка совместимости:**
     - Сокет процессора и материнской платы (AM5 / AM4 / LGA1700).
     - Поддерживаемый тип памяти (DDR4 vs DDR5).
     - Форм-фактор платы и корпуса (ATX, Micro-ATX, Mini-ITX).
     - Длина видеокарты и допустимое внутреннее пространство корпуса (мм).
     - Крепления кулера под сокет и рассеиваемый TDP vs TDP процессора.
     - Энергопотребление системы (TDP CPU + TDP GPU + периферия × 1.35) vs мощность БП и минимальные требования видеокарты.
   - Готовые проверенные пресеты («Бюджетный народный», «Оптимальный 2K Gaming», «Флагман 4K RTX 4090») + специальный пресет для демонстрации срабатывания проверок несовместимости.
4. **Калькулятор апгрейда и модернизации ПК:**
   - Указание текущей конфигурации системы (поколение CPU, объём RAM, тип диска).
   - Выбор цели (FPS в играх, ускорение системы, наращивание RAM, обновление платформы, тишина и охлаждение).
   - Трёхуровневый расчёт решений («Экономный», «Оптимальный баланс», «Максимум мощности») с прогнозом прироста производительности и сметой.

### 2. 📱 Структура страниц и навигация
- **Главная страница:**
  - Шапка с адаптивным мобильным меню, прямым номером и кнопкой записи.
  - Первый экран (Hero) с девизом *«Возвращаем технику к жизни»*, интерактивной диагностической панелью и ключевыми метриками.
  - Блок из 6 ключевых преимуществ лаборатории.
  - 6 карточек направлений ремонта с фото, типичными поломками и ссылками.
  - Блок популярных услуг с фиксированными ценами и сроками.
  - 6-шаговый прозрачный процесс *«Как мы работаем»*.
  - Статистика центра (с демонстрационным дисклеймером).
  - Карточки отзывов клиентов с фильтрами по типам устройств.
  - FAQ-аккордеон с ответами на 7 обязательных вопросов ТЗ.
  - Финальный призыв к действию (CTA).
  - Подвал с навигацией, картой сайта, политикой конфиденциальности и соцсетями.
- **Страница услуг (`#services`):**
  - Подробные спецификации всех 6 направлений с перечнем типичных неисправностей, вариантами компонентного ремонта, сроками и прайс-листами.
- **Страница «О нас» (`#about`):**
  - Принципы компонентного ремонта (пайка элементов вместо дорогой блочной замены).
  - Оснащение лаборатории: ИК-станция «Термопро ИК-650», осциллограф Rigol, микроскоп 90x, тепловизор Fluke Ti480.
  - Регламент антистатической защиты (ESD) и регламент конфиденциальности данных клиентов (NDA).
- **Страница контактов (`#contacts`):**
  - Прямые телефоны, email, режим работы, парковка.
  - Интерактивная векторная карта с пешими маршрутами от метро (Сухаревская, Проспект Мира) и схемой проезда к парковке.
  - Форма обратной связи.
  - Ссылки на Telegram, WhatsApp, VK.

### 3. 🛡️ Формы и защита от ошибок
- Маска ввода телефона: `+7 (XXX) XXX-XX-XX` с проверкой корректности.
- Валидация всех обязательных полей.
- Защита от повторной отправки (anti-double-click).
- Сохранение заявок в локальном реестре браузера (LocalStorage) с присвоением ID.
- Анимация подтверждения с конфетти (`canvas-confetti`).
- Честное уведомление о демонстрационном режиме обработки данных.

### 4. ⚙️ Централизованная конфигурация
Все контактные данные, телефоны, адреса, ссылки на мессенджеры и гарантийные сроки вынесены в единый конфигурационный файл:
`src/config/siteConfig.ts` — для замены данных достаточно отредактировать этот файл.

## 🚀 Инструкция по запуску

### Предварительные требования
- Node.js версии 18+ (проверено на Node.js v24)
- npm версии 9+

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки (Dev Server)
```bash
npm run dev
```
После запуска откройте в браузере адрес: `http://localhost:5173`

### Запуск автоматических тестов калькуляторов
В проект включен набор автоматических тестов, проверяющих математику расчётов и алгоритмы совместимости ПК:
```bash
npm test
```
*Успешно выполняется 26 автоматических проверок.*

### Сборка production-версии
```bash
npm run build
```
Готовая оптимизированная сборка будет сохранена в папку `dist/`.

### Предпросмотр production-сборки
```bash
npm run preview
```

## 🛠️ Стек технологий

- **Фреймворк:** React 18 (TypeScript)
- **Сборщик:** Vite 5
- **Стилизация:** Tailwind CSS 3 (с кастомной темой Dark Cyber / Electric Cyan)
- **Иконки:** Lucide React
- **Эффекты:** Canvas Confetti
- **Тестирование:** TSX / Node Test Suite
- **Доступность & Анимации:** Поддержка `prefers-reduced-motion`, семантическая разметка HTML5, фокус-ловушки в модальных окнах, OpenGraph и мета-теги.

2. **Калькулятор обслуживания ПК (6.2):** Проверка базовых сумм, скидки 15% за комбо из 3+ услуг и пакетного тарифа (3 900 ₽).
3. **Конфигуратор ПК (6.3):**
   - Успешная сборка AM5 + DDR5 + RTX 4070 SUPER.
   - Детекция ошибки несовместимости сокета (Intel LGA1700 в сокет AM5).
   - Детекция ошибки несовместимости памяти (DDR4 на плате DDR5).
   - Детекция ошибки габаритов (ATX плата в Micro-ATX корпус).
   - Детекция превышения длины видеокарты (348 мм > 330 мм).
   - Детекция дефицита мощности БП (650W для RTX 4090 с требованием от 850W).
4. **Калькулятор апгрейда (6.4):** Валидация всех 5 сценариев с формированием 3 пакетов (бюджет, баланс, максимум).
