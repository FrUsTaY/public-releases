# Учёт расходов

Небольшое консольное приложение на Python 3.12 для учёта расходов.

## Файлы

- `main.py` — точка входа приложения.
- `expenses.json` — файл с данными о расходах (создаётся автоматически при первом добавлении).

## Установка зависимостей

Требуется только стандартная библиотека Python. Дополнительные зависимости не нужны.

## Запуск

```sh
python main.py <команда> [аргументы]
```

## Команды

### Добавление расхода

```sh
python main.py add 1500 еда
```

- сумма должна быть положительным числом;
- категория не должна быть пустой.

### Просмотр всех расходов

```sh
python main.py list
```

### Сумма расходов по категориям

```sh
python main.py totals
```

## Примечание

Файл `expenses.json` создаётся приложением автоматически при первом добавлении расхода, если он ещё не существует.
