# Консольный учёт расходов (Expense Tracker)

Небольшое консольное приложение на Python 3.12 для учёта персональных расходов.

## Возможности
- Хранение всех операций в локальном файле `expenses.json` (создаётся автоматически, если отсутствует).
- Добавление расхода с указанием суммы и категории.
- Валидация входных данных: сумма должна быть строго больше 0, категория не должна быть пустой.
- Просмотр списка всех расходов с деталями (ID, дата, категория, сумма) и общим итогом.
- Вывод суммы расходов с группировкой по категориям.
- Поддержка двух режимов работы: аргументы командной строки (CLI) и интерактивное меню.
- Использует только стандартную библиотеку Python (без сторонних зависимостей).

## Требования
- Python 3.12 (или 3.10+)

## Инструкция по запуску

### 1. Интерактивный режим (меню)
Запустите скрипт без аргументов:
```bash
python main.py
```
Откроется текстовое меню с выбором действий (добавление, просмотр, статистика, выход).

### 2. Режим командной строки (CLI)

- **Добавить расход:**
  ```bash
  python main.py add 350.50 "Продукты"
  python main.py add 1200 "Транспорт"
  ```

- **Посмотреть все расходы:**
  ```bash
  python main.py list
  ```

- **Посмотреть сумму расходов по категориям:**
  ```bash
  python main.py summary
  ```
  *(также доступны псевдонимы `stats` и `categories`)*

- **Справка по командам:**
  ```bash
  python main.py --help
  ```
