# Учёт расходов

Консольное приложение на Python 3.12 для учёта расходов. Данные хранятся в файле `expenses.json` (создаётся автоматически).

## Запуск

```bash
python main.py <команда> [аргументы]
```

## Команды

- `add <сумма> <категория>` — добавить расход  
  Пример: `python main.py add 1500 Продукты`
- `list` — показать все расходы
- `summary` — общая сумма расходов по категориям

## Примеры

```bash
python main.py add 1200 Транспорт
python main.py add 350.50 Кафе
python main.py list
python main.py summary
```

Требования: сумма должна быть положительной, категория — не пустой. Используется только стандартная библиотека Python.
