# Учёт расходов

Требуется Python 3.12 или новее. Приложение использует только стандартную библиотеку, а данные хранит в `expenses.json` в текущей папке. Файл создаётся автоматически при первом запуске.

```bash
python main.py add 1250.50 продукты
python main.py add 300 транспорт
python main.py list
python main.py summary
```

Сумма должна быть положительной, категория — непустой. Команда `summary` выводит общую сумму по каждой категории.
