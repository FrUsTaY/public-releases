# PIXEL SERVICE - Сайт цифрового сервисного центра

Современный сайт профессионального сервисного центра по ремонту цифровой электроники и компьютерной техники.

## Описание

PIXEL SERVICE - это визуально привлекательный, современный и интерактивный сайт для сервисного центра, специализирующегося на ремонте:

- Настольных компьютеров и игровых ПК
- Ноутбуков и ультрабуков
- Смартфонов и мобильных телефонов
- Планшетов
- Видеокарт
- Материнских плат
- Процессоров и систем охлаждения
- Блоков питания
- Оперативной памяти и накопителей SSD/HDD
- Игровых консолей
- Периферии

## Технологии

- **React 18** - современная библиотека для создания UI
- **TypeScript** - типизированный JavaScript
- **Vite** - быстрый сборщик и dev-сервер
- **Tailwind CSS** - utility-first CSS фреймворк
- **Framer Motion** - анимации и трансitions
- **Lucide React** - иконки

## Установка и запуск

### Требования

- Node.js версии 18 или выше
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Запуск dev-сервера

```bash
npm run dev
```

Сайт откроется в браузере по адресу `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

Собранный сайт будет в папке `dist`

### Предпросмотр сборки

```bash
npm run preview
```

## Калькуляторы

### Калькулятор стоимости ремонта
- Выбор типа устройства (ноутбук, ПК, смартфон, планшет)
- Выбор неисправности
- Выбор дополнительных услуг
- Расчет итоговой стоимости

### Калькулятор обслуживания ПК
- Выбор услуг обслуживания
- Автоматический подсчет стоимости

### Калькулятор сборки ПК
- Подбор компонентов (процессор, материнская плата, ОЗУ, SSD, видеокарта, корпус, охлаждение, БП)
- Проверка совместимости:
  - Сокет процессора и материнской платы
  - Тип оперативной памяти
  - Форм-фактор материнской платы и корпуса
  - Длина видеокарты
  - Мощность блока питания

### Калькулятор апгрейда ПК
- Рекомендации по модернизации
- Опции: замена видеокарты, процессора, ОЗУ, SSD, система охлаждения
